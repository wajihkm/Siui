# The demo

Three worlds to try siui on any project, in order: `demo-1-scaffold` (a new or young
folder: identity, structure, quality, then apply), `demo-2-hardening` (a tool that works
and now meets failures, limits and restarts) and `demo-3-ux` (the shape of a page or panel
around its use). Start one with `/siui on demo-1-scaffold`.

They are packs: the format is the decision-cards skill's (one markdown file per world,
its fixed facts, its levels with cards and options, a boss last). A project keeps its own
packs in `.claude/skills/decision-cards/packs/` or in the folders its `.claude/siui.json`
names under `packs`; the plugin ships only these three.
