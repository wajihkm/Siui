---
name: siui-status
description: "Siui: where the run stands, and the next card (/siui-status)"
disable-model-invocation: true
---

Call the Siui `status` tool and show its text to the user as it is. Then present the next
card it names, with no text before it. With nothing to present and the board's page open,
call the Siui `listen` tool and wait for the user's next move there.
